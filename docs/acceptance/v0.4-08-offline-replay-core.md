## Safety boundary (offline only)

The replay output is an offline `ReplaySink.emit`; there is no `CanAdapter.send`,
no python-can TX, no hardware TX, no ARM state and no Safety Kernel authorization
implementation. `tests/unit/replay/test_replay_offline_only.py` asserts this
(structural + source-token + subprocess `sys.modules` checks) rather than
promising it.
