## Implemented across V0.1.1

- **A — documentation naming**: singular `AGENT.md` references replaced with canonical `AGENTS.md`; negative scan `grep 'AGENT\.md'` returns nothing.
- **B/C/D — recorder pressure**: ADR 0001 policy implemented — capture continues after a recorder pressure/write failure while the session becomes `degraded`; finite archive deadline, structured observable failure, bounded stop. Saturation test plus a new slow-disk soak test.
- **E/F — shared frontend realtime stream**: one workspace-owned store (`realtime-stream.ts`) holds a single WebSocket + single Worker; Trace and Plot are projections of it. Trace freeze is a Trace-only cursor and does not pause the socket/Worker/Plot. Consumers are reference-counted; the socket and worker open once and close once.
- **G — packaged Python runtime**: PyInstaller (`packaging/canx-runtime.spec`, `scripts/build-runtime.cmd`) produces `canx-runtime.exe`; the desktop resolves the bundled executable in production (`#[cfg(not(debug_assertions))]`) and never falls back to a system Python, keeping `CANX_RUNTIME_PYTHON`/repo `.venv` for development.
- **H — Tauri distribution**: bundle enabled with icons and the sidecar as an `externalBin`; `scripts/tauri-bundle.cmd` produces an MSI whose WiX manifest ships `canx-runtime.exe`.
- **I — smoke path**: `tests/integration/test_packaged_runtime_smoke.py` drives the packaged `canx-runtime.exe` through health → capture → binary stream → flush → authenticated shutdown → exit 0.
- **J — instrumentation**: the Worker records a monotonic per-batch decode duration, surfaced on the shared store and shown in the workspace status.
- **K/L/M — regression, report, state**: full matrix green; this report; `docs/PROJECT_STATE.md` updated.

## Known limitations and NOT VERIFIED

- **Windowed desktop launch** cannot run under the host execution policy; only the runtime half of the smoke path is verified. GUI launch is **NOT VERIFIED**.
- **Latency**: only Worker decode duration is instrumented. Runtime→WebSocket latency, Trace render latency, and Plot update latency remain **NOT VERIFIED**; the benchmark placeholders in `runtime/canx/benchmarks/v01_pipeline.py` still report `NOT VERIFIED`.
- **NSIS** bundling failed on a WiX→NSIS download timeout, so `bundle.targets` is restricted to `msi`. MSI is the verified Windows artifact.
- **PyInstaller onefile** spawns a child process; a forced kill of the bootloader alone can leave the child running. The supported path is the authenticated `/runtime/shutdown`, which exits cleanly (verified).
- **Physical CAN hardware**, error frames, hardware timestamps, bus-off, and TX policy remain **NOT VERIFIED**. **macOS** remains **NOT VERIFIED**.
- No CAN-Space/CanLab code is reused, so `docs/REUSE_LEDGER.md` is not created.
